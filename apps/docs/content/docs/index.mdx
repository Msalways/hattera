Hattera is a self-hosted browser app for chatting with AI agents. It is a fork of [OpenMausBot](https://github.com/milind-soni/OpenMausBot) with owner-only GitHub sign-in, a Compose deployment, and a disposable Render preview option.

<Cards>
  <Card title="Set up Hattera" href="/docs/setup" description="Build this fork locally, connect your GitHub account, and pair a browser." />
  <Card title="Use the browser app" href="/docs/capabilities" description="Bots, conversations, models, tools, skills, memory, and access settings." />
  <Card title="Choose hosting" href="/docs/hosting" description="Understand the data and uptime tradeoffs before deployment." />
</Cards>

Hattera retains upstream protocol names, `OMB_*` configuration, storage paths, and Compose volumes for compatibility. Upstream desktop releases and MausBot Cloud subscriptions are separate products and are not Hattera releases or services.

The source and legal notices are in the [Hattera repository](https://github.com/Msalways/hattera). Hattera remains based on OpenMausBot by Milind Soni and contributors under the licenses recorded there.
