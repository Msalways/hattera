---
title: Browser capabilities
description: What you can do in Hattera's browser app.
icon: MessageCircle
---

The browser app lets you create bots, open conversations, send messages, and adjust each bot's identity, model, working folder, tools, skills, memory, and access. Settings also expose configured engines and connected services. Available controls depend on server configuration, permissions, and whether an engine is installed and signed in.

The chat, bot settings, model picker, tools, skills, memory, and responsive navigation are inherited from Hattera. Hattera changes their browser presentation while preserving bot data and API contracts. Existing `OMB_*` settings, stored paths, and protocol identifiers remain valid.

Hattera does not include a new SDK or new model subscription. Agent engines and any optional connected services use their own authentication and billing. The desktop release identity is a separate future migration.
