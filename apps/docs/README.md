# Hattera public docs

This Next.js site documents the Hattera browser fork. The navigation covers this fork's Compose setup, browser capabilities, and hosting choices. Inherited OpenMausBot pages remain in `content/docs` for upstream reference but are outside Hattera's public navigation until reviewed for this fork.

From the repository root, install dependencies and run `pnpm docs:dev` for a local preview or `pnpm docs:build` for a production build. The docs app alone does not deploy the Hattera server, agents, credentials, or user data. See the root [README](../../README.md) and [license notices](../../LICENSING.md) for the product setup and upstream attribution.
